== 관리자 공간

이 절에서는 MockMvc를 단독으로 구성해 실제 `AdminSpaceBffController`를 호출하고 확인한 관리자 공간 BFF 계약을 안내합니다.
인증 필터와 관리자 권한 정책은 이 테스트 범위에 포함하지 않습니다.
