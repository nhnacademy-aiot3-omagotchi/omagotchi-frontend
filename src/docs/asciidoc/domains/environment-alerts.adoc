== 환경 및 공실 알림 BFF

이 문서는 MockMvc를 단독으로 구성해 BFF 컨트롤러를 호출하고 확인한 성공 응답 계약을 안내합니다.
테스트에서는 `SESSION` 쿠키를 자리표시자로 전달하지만 실제 인증 쿠키 필터와 전체 보안 설정은 검증하지 않습니다.
