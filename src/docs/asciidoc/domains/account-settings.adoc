== 계정 설정 BFF

=== 공통 계약

인증에는 서버 세션과 `SESSION` 쿠키를 사용합니다. 문서에서는 세션 식별자를 `[SESSION_ID]`로 표시합니다.

비밀번호 요청 예시의 `currentPassword`와 `newPassword` 값은 `[REDACTED]`로 표시합니다.

모든 개인 계정 응답과 오류 응답은 `Cache-Control: no-store`를 반환합니다.
