== 관리자 계정·감사

이 절에서는 MockMvc를 단독으로 구성하고 애플리케이션 서비스의 응답을 모의해 확인한 관리자 계정 BFF의 HTTP 계약을 안내합니다.
실제 Spring 보안 필터 체인의 관리자 권한·세션 인증 검증은 포함하지 않습니다.
