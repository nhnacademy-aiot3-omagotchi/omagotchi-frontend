== 기수

이 절에서는 로그인한 브라우저 세션의 요청을 처리하는 기수 BFF의 HTTP 계약을 안내합니다.
테스트는 모의 하위 서비스 응답을 사용하므로 Spring 보안 필터 체인의 인증·인가를 검증하지 않습니다.
실제 애플리케이션에서는 브라우저 세션에서 인증 정보를 읽고 하위 Learning 서비스를 호출할 때 Access Token을 전달합니다.
