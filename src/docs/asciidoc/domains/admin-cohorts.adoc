== 관리자 기수

이 절에서는 단독으로 구성한 컨트롤러 테스트와 모의 Learning 프록시 응답으로 확인한 관리자 기수 BFF 계약을 안내합니다.
브라우저 세션 인증과 관리자 권한 필터 체인 자체는 이 테스트 범위에 포함하지 않습니다.
