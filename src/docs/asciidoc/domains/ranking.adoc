== 학습 랭킹 BFF

랭킹은 인증 세션에 저장된 승인 기수를 기준으로 조회합니다. 브라우저에서 기수 ID를 보내지 않으며,
BFF가 세션 정보를 바탕으로 하위 Learning 요청의 `Authorization` 헤더와 기수 ID를 구성합니다.
