== 학습 통계 BFF

관리자 학습 통계 BFF는 경로의 기수 ID와 조회 기간을 하위 Learning 서비스에 전달합니다. 아래 문서는
보안 필터를 통과한 인증 요청을 기반으로 하며, 내부 `Authorization` 헤더는 브라우저 계약에 포함하지 않습니다.
