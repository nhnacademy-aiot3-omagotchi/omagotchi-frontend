== 회원가입·비밀번호 재설정 BFF

이 절은 `SecurityConfig`를 실제로 가져와 사용하는 `@WebMvcTest` 계약 테스트에서 생성합니다. 익명 브라우저에 공개되는 범위, 상태 변경 요청의 CSRF 보호, `Cache-Control: no-store`, 오류 JSON 변환을 실제 보안 필터 체인과 함께 검증합니다. 브라우저에서 CSRF 토큰을 페이지에서 받은 뒤 요청 헤더에 담아 보내야 합니다.

=== 회원가입 오류

OTP 형식이 잘못되면 `400 Bad Request`와 `COMMON_INVALID_REQUEST`를 반환합니다. 인증 요청이 거절되면 `400 Bad Request`와 `EMAIL_VERIFICATION_INVALID_CHALLENGE`를 반환합니다. OTP 재발급 대기 중에는 `429 Too Many Requests`와 남은 시간을 `Retry-After` 헤더로 전달합니다.
