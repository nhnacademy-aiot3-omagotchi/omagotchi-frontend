== AI 채팅 BFF

=== SSE 채팅

세션의 Access Token으로 Learning 서비스를 호출하고 AI 응답을 SSE로 전달합니다.
테스트에서는 실제 `Flux<String>` 조각을 비동기 디스패치로 완료해 `text/event-stream` 응답과 한글 본문을 확인합니다.
`SESSION` 쿠키는 자리표시자이며 실제 인증 쿠키 필터와 전체 보안 흐름은 테스트 범위에 포함하지 않습니다.
Learning 서비스 호출 실패와 스트림 종료 오류는 BFF의 공통 오류 처리에서 다룹니다.
