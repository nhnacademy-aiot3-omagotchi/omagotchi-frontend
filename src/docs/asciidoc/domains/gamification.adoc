== 게이미피케이션 BFF

Frontend는 Learning 서비스의 게이미피케이션 응답을 브라우저 세션 기반 BFF를 통해 전달합니다. 응답 JSON은 Learning 서비스의 실제 `GameCharacterResponse`, `UserCharacterResponse`, `HomeResponse`, `DailyQuestResponse`, `GamificationProgressionResponse`, `StudyTimePredictionResponse` 필드를 따릅니다.
