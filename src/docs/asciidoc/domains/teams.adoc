== 팀 BFF

팀 BFF는 인증된 브라우저 세션을 위한 팀 관리 API를 제공합니다. 하위 Learning 서비스에 전달하는 `Authorization` 헤더는
브라우저 요청 계약에 포함하지 않습니다.
