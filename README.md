# Omagotchi Frontend

Spring MVC와 Thymeleaf를 사용하는 Omagotchi의 화면 애플리케이션입니다.

## 실행

```bash
./mvnw test
./mvnw spring-boot:run
```

- 요구 사항: JDK 21
- 기본 화면: <http://localhost:8082/>
- 상태 확인: <http://localhost:8082/actuator/health>
